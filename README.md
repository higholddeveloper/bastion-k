# Бастион К: сайт охранного агентства

Лендинг охранного агентства «Бастион К» (Бишкек, Кара-Балта). React 18, Tailwind CSS 3, lucide-react. Сборка даёт один файл `index.html` в корне со стилями и скриптом внутри. Фото лежат рядом, в папке `assets/`.

Версия: **variant-3-green** с фото охранников и автомобиля группы быстрого реагирования.

## Запуск

```bash
npm install
npm run build      # результат: index.html в корне проекта
```

Открыть `index.html` в браузере. Для GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`. Шрифты (Oswald, Onest, JetBrains Mono) подгружаются с Google Fonts.

## Что внутри

- `src/App.jsx`: страница целиком. Данные компании, услуги, оборудование (`EQUIPMENT`), преимущества, вопросы лежат константами в начале файла.
- `src/main.jsx`: точка входа и переключатель палитр A/B/C/D внизу экрана. Для боевого сайта переключатель нужно убрать (`PaletteSwitch`) и оставить одну палитру в `src/input.css`.
- `src/input.css`: цветовые токены четырёх палитр на основе логотипа (глубокий зелёный `#0b4d3f` и серебро).
- `assets/*.webp`: фото сайта в двух размерах (`-800` для телефонов, `-1600` для больших экранов). Подключаются через компонент `Photo` в `src/App.jsx`.
- `assets/hero.mp4`: hero-видео (1280×720, без звука, один файл для всех устройств, как выложил заказчик), `hero-start-*.webp` постер (первый кадр), `hero-end-*.webp` последний кадр для режима «без анимации».
- `assets/bastion-k.svg`: векторный логотип.
- `index.template.html`: оболочка страницы (title, description, Open Graph, JSON-LD `SecurityService`).
